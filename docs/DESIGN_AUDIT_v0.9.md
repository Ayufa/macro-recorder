# デザイン監査 v0.9（android-design-guidelines に沿った修正）

基準: [ehmo/platform-design-skills](https://github.com/ehmo/platform-design-skills) の `android-design-guidelines`
（MIT、commit `dc2be825`）。10 セクション（R1〜R10）・評価チェックリスト・アンチパターン表のすべてを、
アプリの全画面（メイン画面・セットアップ・マクロ一覧の行・長押しメニュー・再生設定シート・ダイアログ・
フローティングのバブル / パネル・ユーザー補助サービスの設定）と照らし合わせました。

このアプリは Jetpack Compose / AndroidX を使わず、フレームワークのビューだけで作っています。ガイドラインの
Compose の API 名（`MaterialTheme.typography`、`enableEdgeToEdge()`、`WindowSizeClass` など）は、同じ
意図のフレームワーク版（`Ui.Type`、`WindowInsets`、`Configuration.screenWidthDp` など）で満たしています。

重要度: **高** = 使えない人が出る / ポリシーに関わる、**中** = 明らかな不整合や使いにくさ、**低** = 仕上げ。

## 指摘と修正

### 1. Material You とテーマ

| # | ルール | 重要度 | v0.8 | v0.9 |
| --- | --- | --- | --- | --- |
| 1-1 | R1.9 | 高 | テーマを手動で選べない | アプリの設定に「テーマ（端末の設定 / ライト / ダーク）」の行。Android 12+ は `UiModeManager.setApplicationNightMode`、それより前はアプリ内で設定を当て直す（`ThemeMode`） |
| 1-2 | R1.11 / R1.1 | 中 | Android 12+ でもダイナミックカラーは一部の色だけ | `values-v31` で primary / container / surface / on-surface / outline / inverse / 方眼まで `system_accent1/2・neutral1/2` に。Android 14+ は `system_*_light/dark` の M3 ロール（`values-v34`）。12 未満は固定のパレット |
| 1-3 | R1.8 | 中 | ダークの背景がほぼ黒（`#09090B`） | トーンで段階をつけたサーフェス（`#111113` / `#18181B` / `#1F1F23`） |

## 適用しなかったもの / 一部だけ

- **R6.6（パネルのボタンの横幅）**: 幅 412dp 未満の画面で横 48dp にすると、パネルが画面からはみ出します。縦は 48dp にして、横はそれまでどおり 32〜40dp（ボタン同士の間はすき間なし）にしました。
- **R5.14（トースト）**: 「3秒後に再生」はアプリが後ろへ下がるときに出すので、トーストのままです。ユーザー補助サービスのパネル（画面の上のフローティング）にはスナックバーを置ける親の画面がないので、そこもトーストのままです。
- **R1.3（壁紙3種で確認）**: 実機・エミュレーターで確認できなかったため未確認（下の「確認したこと」）。
- **Android 12 未満でのテーマ変更**: アプリの画面はすぐ変わり、パネルは次に作り直したときに新しい色になります。
- **R2.1〜R2.9 / R3.9 / R3.10 / R8 / ウィジェット**: 該当する画面がありません。
- **既存のデザイン（v0.6〜v0.8）**: 方眼のヘッダー、等幅のバッジ、ドットのアニメーション、行の左端の線などは、ガイドラインと矛盾しないので残しました。

## 確認したこと

- ビルド（standard / monetized）、単体テスト（PanelMath 412→48・392→40・360→40・340→36・280→32 を含む）
- lint（standardDebug）: Accessibility カテゴリの指摘 0（途中で出た `AccessibilityFocus` は、a11y フォーカスの強制をやめて解消）、エラー 0
- aapt: versionCode 9 / 0.9、minSdk 26 / targetSdk 37、権限は `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` のみ。dexdump: 広告・課金のクラス 0。apksigner: 署名 OK
- コントラスト比は計算で確認（WCAG の式）
- エミュレーター: 起動を1回試しましたが、これまでと同じく起動途中で止まったため、画面での確認はできていません
