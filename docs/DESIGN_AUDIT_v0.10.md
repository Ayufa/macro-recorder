# デザイン監査 v0.10（unslop の方法による組み直し）

基準: [heydamir/unslop](https://github.com/heydamir/unslop)（Damir Sokolovsky、CC BY 4.0）の方法。
「AI が作ったように見えるサイン」を先に洗い出し、製品から方向を決め、余白→色→アイコン→文言→書体→
レイアウト→細部→装飾→動きの順に直す。出典と採用した値は `THIRD_PARTY_NOTICES.md` に記録。

v0.9 の android-design-guidelines 監査で入れたもの（48dp のタッチ領域、コントラスト 4.5:1、
M3 の型スケール、元に戻せる削除、TalkBack 対応など）は維持する。unslop の値のうちタッチ端末に
合わないもの（行高 32〜36 など）は採らない。

## 方向（あゆさん承認済み、2026-10-31）

- **Product**: 自分のタップとスワイプを記録して、そのまま再生する個人用レコーダー
- **Character**: 精密、計器、静か
- **World**: 録音機と計測器。タイムコード、録画ランプ、ストップウォッチ
- **Moments**: 色が生きるのは記録・再生の「状態」だけ。録画の赤いドットと進捗リング、その他は全部静かに
- **Signature**: タイムコード風の等幅数字。長さ・件数・速度の数字を、ピルをやめて静かな等幅メタ表示に統一
- アクセントは Material You の端末色ではなく**固定色**（コバルト）にする

## 監査で見つけたサイン（v0.9.1 時点）

重度ではない。グラデーション、グロー、絵文字アイコン、煽り文句、感嘆符は最初から無い。

| # | サイン | 場所 |
| --- | --- | --- |
| 1 | セクション見出しが大文字＋字間 0.12 の等幅ラベル | `Ui.sectionLabel` |
| 2 | 何でもピル形（ボタン・バッジ・チップが角丸 999、カード 20、シート 24）で角丸に階層がない | `Ui.button / badge / FilterChip / card / sheetBackground`、各画面 |
| 3 | ヘッダー背景の方眼グリッド（装飾の filler） | `MainActivity` ヘッダー、`GridDrawable` |
| 4 | バージョン・件数・手順数がピル型バッジ | `Ui.badge` の呼び出し全般 |
| 5 | バウンスする動き（オーバーシュート）と、全要素へのスタッガー登場、イージングが複数 | `Motion.pop / enter`、`Ui.pressable` |
| 6 | 余白に 4dp グリッド外れ（14 / 10 / 7 / 5 / 3 など）が散在 | 主要画面、シート |
| 7 | 20sp 以上の文字に字間 −0.02 | `Ui.text` |
| 8 | 色に製品固有の顔がない（12+ は端末色、未満は汎用ブルー #0066FA） | `values*/colors.xml` |
| 9 | 見出し類が一律 SEMIBOLD(600) | 各画面のタイトル、`Ui.kbd` |
| 10 | ランチャーアイコンの背景が紫→ピンクのグラデーション＋光の円（unslop が真っ先に挙げるサイン） | `res/drawable/ic_launcher_bg.xml` |

## パスごとの変更

### 1. 余白
- 主要画面・シート・ダイアログの余白を 4dp グリッドに寄せた（14→16、10→8/12、6→4、3→4 など）。
- 光学的に中央に置くための値（34dp の丸に 20dp アイコンを置く 7dp など）と、48dp タッチ領域を
  確保する透明余白は意図的なので残した。

### 2. 色
- `values-v31 / values-night-v31 / values-v34 / values-night-v34`（Material You のシステム色）を廃止し、
  全 API レベルで固定パレットに統一。**v0.9 の R1.1 / R1.11（ダイナミックカラー）は意図的に置き換えた。**
- ニュートラルは unslop の ink ランプ（ライト: 背景 #F5F7FA / カード #FFFFFF / 段差 #ECEFF4 /
  主文字 #111827、ダーク: #0B0D14 / #11141C / #1A1E28 / #EEF0F5）。
- アクセントはコバルト 1 色（ライト #1D4ED8、ダーク #7AA5FF）。主操作・選択中・スライダー・
  フォーカス・リンクだけに使う。主ボタン（FILLED）は従来どおり墨色。
- 意味色は据え置き〜微調整（記録の赤、成功の緑は unslop のダーク意味色 #4CC38A に合わせた）。
- 文字色と境界線のコントラストは計算で再確認した（文字 4.5:1 以上、md_outline は 3:1 以上）。
  ink_3 は載る面すべてで 4.5:1 を満たす値に調整（ライト #5A6376、ダーク #838BA0）。
- `md_grid` はヘッダー方眼の廃止に伴い削除。

### 3. アイコン
- 変更なし。もともと Material の線アイコン 1 セットで、色は文字の役割から取る作りだった。

### 4. 文言
- 変更なし。感嘆符・煽り言葉は無く、句点が残るのは複数文の段落とヒント文だけ（unslop でも許容）。
  ラベルとボタンに句点は無い。

### 5. 書体
- セクション見出し: 大文字化（`isAllCaps`）と字間 0.12 を廃止し、文頭ケースの等幅 12sp に。
- `Ui.text` の負の字間（−0.02）を廃止。
- タイトル類（ダイアログ見出し、セットアップ、設定シート、マクロ名）と `kbd` を SEMIBOLD(600) → MEDIUM(500) に。
  階層は太さではなく大きさと色で付ける。手順番号の小さな等幅数字だけ 600 を残した。

### 6. レイアウト
- 変更なし。セクションの構成と順序は維持（unslop の原則どおり）。

### 7. 細部（角丸）
- 役割で統一: 操作部品（ボタン・チップ・入力欄）10dp / カード 16dp / パネル・ダイアログ・シート 20dp。
- 入れ子は「外 − 余白」: セグメントはトレイ 16 − 余白 4 = 中 12 にそろえた。
- 円形のもの（手順番号、状態の丸、バブル）は形として円のまま。
- バッジはピルをやめ、背景・枠なしの等幅メタテキストに（`Ui.badge`）。色は役割だけを表す。

### 8. 装飾
- ヘッダーの方眼（`GridDrawable`）を削除し、静かな面にした。
- ランチャーアイコン: 背景のグラデーションと光の円をやめ、墨色（#171B26）の単色にした。
  前面のグリフ（白い進行リングと再生三角、赤い記録ドット）はそのまま。色は記録ドットだけが持つ。
- ドットマトリクスは「状態」を表す場所（表示中・記録中・再生中）だけに残し、装飾としては増やさない。
  空の状態の表示は従来どおり（製品のモチーフとして 1 か所だけ）。

### 9. 動き
- イージングを 1 本に統一: cubic-bezier(0.22, 1, 0.36, 1)（`Motion.easeOut`）。
  BlurFade 由来の長さ・オフセット・ぼかし（0.4s / 6dp / 6px）は維持し、専用 ease は廃止。
- `Motion.pop` のオーバーシュートを廃止（0.96 → 1.0、200ms、easeOut）。
- 押し込みは 0.95 → 0.97、時間は 120 / 200ms に統一。
- 登場のスタッガーは先頭 5 つまでに制限。

## 確認したこと

2026-10-31、引き継ぎ先の環境（JDK 17 ビルド / JDK 21 テスト、Android SDK 37）で実施。

- 単体テスト全 26 件合格（`LaunchTest` 15 件含む。UI 変更後の起動・表示崩れなし）。
- lint はエラー 0（警告のみ、従来からのもの）。
- APK（standardDebug）を確認: versionCode 11 / versionName 0.10.0、minSdk 26 / targetSdk 37、
  権限は `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` のみ（INTERNET なし）、
  広告・課金 SDK のクラス混入 0。
- 署名について: この環境で新規に生成したデバッグ鍵で署名した（あゆさんの了承済み）。
  そのため v0.9.1 からの上書きインストールはできず、初回のみアンインストールが必要
  （保存済みマクロは消える。了承済み）。この鍵を今後の正規の署名鍵とし、
  v0.10.0 以降は上書きインストールできる。
- 実機（Galaxy S26 Ultra）での見た目の確認はあゆさん待ち。
