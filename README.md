# 操作マクロ（macro-recorder）

Android 用の画面操作マクロアプリです。タップ・長押し・スワイプを記録して、あとで自動で再生できます。root 不要。

- ユーザー補助サービス（AccessibilityService）の `dispatchGesture` で操作を再生
- 記録中は透明なオーバーレイで指の動き（座標と時間）を受け取り、その操作をすぐ下のアプリに届けます
- 繰り返し回数（無限も可）・ループ間隔・速度（0.5〜4倍）を設定可能
- マクロに名前を付けて保存／名前変更／削除／実行
- ドラッグで動かせるフローティングパネル（記録・再生・停止・設定・小さくする・隠す）
  - アプリの「表示」ボタンを押したときだけ出ます（ユーザー補助をオンにしたとき・更新・再起動では自動で出ません）
  - 「小さくする」で 48dp の丸いバブルに折りたたみ。記録中は赤い点とリング、再生中は進捗リングを表示
  - 「設定」でアプリのメイン画面に戻る
- 落ち着いたニュートラル配色・角丸カード・ピル型ボタンのデザイン（ダーク／ライト対応）。再生設定は下から出るシート（繰り返しのセグメント、間隔・速度のスライダーとプリセット）
- 多言語対応: English（既定）・日本語・简体中文・繁體中文・한국어・Español。アプリの「アプリの設定 > 言語」か、Android 13 以降は端末の「設定 > アプリ > 操作マクロ > 言語」で切り替え
- **プライバシー**: 他のアプリの画面内容は読み取りません（`canRetrieveWindowContent=false`、イベント購読なし）。データは端末内のアプリ専用領域にのみ保存。`INTERNET` 権限なし。

## インストール

[INSTALL_ja.md](INSTALL_ja.md) を参照してください（Galaxy 向けの手順）。APK は Releases にあります。

## ビルド

```sh
./gradlew assembleStandardDebug   # 配布版: app/build/outputs/apk/standard/debug/app-standard-debug.apk
./gradlew testStandardDebugUnitTest lintStandardDebug
# 収益化版（既定は無効・配布しない）: ./gradlew assembleMonetizedDebug  → docs/MONETIZATION_ja.md
```

JDK 17、Android SDK Platform 37（compileSdk / targetSdk 37、minSdk 26）、AGP 9.5、Gradle 9.8。

### 文言（翻訳）

画面の文言は `tools/strings_data.py` にまとめてあり、`python3 tools/gen_strings.py` で各言語の `res/values*/strings.xml` を生成します（差し込み `%1$s` などが英語と一致しないとエラー）。直接 strings.xml を編集した場合も、`StringsResourcesTest` が全言語のキーと差し込みの一致を確認します。

## 制限

- テキスト入力の記録は未対応
- スワイプは記録した軌跡を一定速度でなぞります（途中で止まる・速さが変わる動きは再現されません）
- 記録中、1つの操作を下のアプリに届けている短い間（画面のふちがオレンジ）のタッチは記録されません
- 画面の向きや解像度が記録時と違う場合は座標を比例変換するだけなので、レイアウトが変わる画面ではずれることがあります
